2020년 취업을 준비하며 HTML과 jQuery로 만든 포트폴리오 사이트가 이 주소에 있었습니다.
6년 동안 거의 손대지 못하고 그대로 두었는데, 이번에 처음부터 다시 만들었습니다.

## 무엇을 바꿨나

- 한 페이지짜리 포트폴리오 → 자기소개·블로그·포트폴리오·이력, 메뉴 4개
- 손으로 쓰던 HTML → Astro (글은 Markdown 파일 하나만 추가하면 됨)
- 파일을 직접 올리던 방식 → push하면 GitHub Actions가 자동으로 빌드·배포

## 왜 Astro + GitHub Pages인가

- 계속 무료로 운영할 수 있고, 계정은 GitHub 하나면 됩니다.
- 페이지를 미리 HTML로 만들어 두니 빠르고, 필요하면 React 컴포넌트도 섞어 쓸 수 있습니다.

## 옮기면서 챙긴 것

- 하루 비서 앱의 개인정보처리방침 주소는 그대로 유지했습니다.
- 예전 프로젝트(OWGG, Holiday Calendar)는 포트폴리오로 옮겼습니다.
- 예전 사이트에 있던 연락처 같은 개인정보는 정리했습니다.

## 앞으로

업무와 사이드 프로젝트를 하면서 배운 것들을 여기에 정리해 보려 합니다.
